개인정보 처리방침

적용일: 2026-09-30. 이 도구는 소유자의 Windows PC에서 사용하는 개인용 영상 제작 도구입니다.

처리 정보와 목적

SNS가 승인한 계정 식별자, 표시 이름, 사용자 이름, 접근 토큰과 갱신 토큰을 계정 확인·연결 유지·영상 전송에 사용합니다. SNS 비밀번호는 앱에 저장하지 않습니다. 영상, 이미지, 대본, 게시 문구 및 게시 결과는 로컬 프로젝트에 저장됩니다.

저장과 외부 전송

SNS 비밀 키와 토큰은 Windows 계정에 연결된 암호화 저장소에 보관합니다. 승인된 영상과 문구는 선택한 SNS API로 전송됩니다. 선택한 제작 서비스에 따라 대본과 이미지 생성 요청이 해당 서비스로 전송될 수 있습니다. 공개 OAuth 복귀 페이지는 인증 응답을 실행 중인 로컬 앱으로 전달하며 별도 분석 코드를 사용하지 않습니다. GitHub Pages 호스팅의 요청 기록에는 URL에 포함된 정보가 기록될 수 있습니다.

보관·삭제·권한 철회

계정 정보는 앱의 연결 해제까지 보관하며 연결 해제 시 해당 연결 정보를 제거합니다. SNS 설정에서도 앱 권한을 철회할 수 있습니다. 로컬 영상과 게시 기록, 백업은 별도로 삭제해야 합니다. 이미 SNS에 전송된 자료는 해당 SNS에서 관리합니다.
